# PROYECTOS

## Padeltracker.es

- **Descripcion (3-4 lineas):**

  Padeltracker.es centraliza resultados, estadisticas de jugador y gestion de partidos para clubes y jugadores amateurs. Permite registrar partidos, generar metricas por jugador y visualizar la evolucion en el tiempo, agilizando la toma de decisiones y el seguimiento del rendimiento.

- **Stack tecnico (bullets):**

  - Next.js 15, TypeScript
  - MongoDB Atlas (produccion)
  - NextAuth (autenticacion)
  - Nginx (reverse proxy) + PM2 (process manager)
  - CI/CD: GitHub Actions -> despliegue a VM en Oracle Cloud

- **Links:**

  - Live: https://padeltracker.es  
  - Codigo: https://github.com/nel386/padeltracker (si aplica)
